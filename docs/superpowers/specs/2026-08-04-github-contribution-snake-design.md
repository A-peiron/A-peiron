# GitHub contribution snake

## Goal

Replace the cached third-party activity line chart in the profile README with a generated contribution-grid snake animation.

## Scope

- Add a GitHub Actions workflow that runs daily and on manual dispatch.
- Generate light and dark SVG variants from the account's public contribution calendar.
- Publish generated files to a dedicated `output` branch.
- Replace only the `GITHUB ACTIVITY` image in `README.md` with a responsive `<picture>` that uses those assets.

## Constraints

- Keep the existing profile prose and typography unchanged.
- Use restrained monochrome colours.
- Do not add badges, cards, or other decorative elements.
- The workflow must have the least permissions needed to write its generated branch.

## Validation

- Workflow YAML is syntactically valid and uses the repository token for branch output.
- README references the generated branch paths for both colour schemes.
- The initial output is generated by a manual workflow run after the change is pushed.
